# Chandini Seelam: portfolio

A fast, static portfolio website. No build step and no dependencies.

## Preview
Open `index.html` in your browser.

## Add your photo (important)
Save one professional photo (front facing, smiling, good light, square crop) as
`assets/photo.jpg`. Until then the site shows a placeholder.

## Replace the project cover images
Take a screenshot of each live demo and save it over the matching file in
`assets/projects/`, then update the `src` in `index.html`:
- `support-ticket-system.svg` -> your screenshot (for example `support-ticket-system.png`)
- `travel-trip.svg`
- `learning-management-system.svg`

## Edit
- Text and links: `index.html`
- Colours and fonts: the variables at the top of `css/style.css`
- Resume: replace `assets/Chandini_Seelam_Resume.pdf` (keep the same file name)

## Contact form
- **Netlify:** works automatically after you deploy. Messages appear under Forms in your Netlify dashboard.
- **Anywhere else (Vercel, GitHub Pages):** the form opens a ready-to-send email draft instead.
  To receive messages directly, create a free form at formspree.io and set the form's `action` to your Formspree URL.

## GitHub stats
The numbers and the contribution calendar load from your public profile (`seelamchandini-2309`)
when the site is online. To change the username, edit `GH_USER` in `js/main.js` and the calendar image URL in `index.html`.

## Deploy for free
- **Netlify:** go to app.netlify.com/drop and drag this folder onto the page.
- **Vercel:** import the folder or a GitHub repo at vercel.com/new. Framework preset: Other.
- **GitHub Pages:** push these files to a repo, then Settings > Pages > Deploy from branch (main, root).

After deploying, add the portfolio link to your resume, LinkedIn and GitHub profile.
